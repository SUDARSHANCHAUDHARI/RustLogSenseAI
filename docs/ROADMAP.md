# Roadmap

This is a solo-maintained roadmap. Items are practical possibilities, not promises.

## Planned

- Add configurable error-rate thresholds.
- Add a Markdown summary output mode.

## Completed

- Stdin input support with `logscope scan -`.

## Maybe Later

- Add timestamp-window analysis.
- Add simple pattern grouping for stack traces.
- Add export examples for support handoff notes.

## Not Planned

- A hosted log ingestion service.
- Long-running log tailing daemon mode.
- GitHub Actions workflow files.

## Feature Blog Angles

- "A small Rust CLI for reading logs before opening a full observability stack"
- "How to design useful log health thresholds"
- "Building deterministic CLI tests around log fixtures"
